### Environment Variables Required:
```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
RAZORPAY_KEY=
RAZORPAY_SECRET=
STRIPE_SECRET_KEY=
OPENAI_API_KEY=
NEXT_PUBLIC_APP_URL=
```

### Database Setup:
1. Run SQL migration from `supabase/migrations/001_initial_schema.sql`
2. Set up Supabase Storage buckets:
   - `product-images`
